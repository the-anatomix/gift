# 트리 같이 꾸미기: 지금 상태와 다음 할 일

주소: https://the-anatomix.github.io/gift/tree/
놀자방 홈(`nolja/index.html`)에는 아직 "곧 열리는 방"으로 둔다. 둘이 같이 꾸미기까지 되면 연다.

## 정해진 것 (기획)
- 딱 2명, 방 링크로 실시간 접속. 서버 없이 브라우저끼리 직접 잇는다(주방과 같은 방식).
- 비스듬히 내려다보는 시점, 폰과 PC 모두. 눌러서 걷고 놓는다.
- 따뜻한 로우폴리, 공동 거실 하나, 가운데 큰 트리.
- 아바타는 머리 큰 사람(치비). 머리 모양·피부색·옷 고르기.
- 기본 장식은 처음부터 다 열려 있고, 특별 장식은 선물상자 찾기와 협동으로 연다.
- 협동 3가지: 꼭대기 별(한 명이 받쳐 주기), 큰 가구(둘이 들기), 점등식(스위치 2개 같이 누르기).
- 1차에 넣는 것: 트리 꾸미기, 가구 배치, 아바타 꾸미기·몸짓·말풍선, 사진 찍기·저장.
- 2차로 미룬 것: 선물 교환, 미니게임, 캐럴·날씨·낮밤.

## 지금 되는 것 (1단계)
- 거실: 마루, 러그, 벽 네 면(창 2, 리스, 액자 2, 문), 가운데 트리
- 카메라: 네 방향에서 돌려 보기(버튼, PC 는 Q·E). 카메라 쪽 벽 두 면은 숨긴다. 화면 크기에 맞춰 방 전체가 들어온다
- 아바타: 치비 사람, 걷는 몸짓. 바닥을 누르면 트리를 돌아서 걸어간다. PC 는 방향키·WASD
- 앱 안 브라우저 안내, WebGL 없으면 안내, 느린 기기에서 화질 낮추기

## 다음 단계
2. 가구 배치(놓기·돌리기·옮기기, 벽지·바닥 바꾸기)와 트리 꾸미기(트리 가까이 보기, 장식 달기, 전구 색·깜빡임)
3. 둘이 실시간 연결(방 링크, 상대 아바타, 놓은 것 바로 보이기)
4. 협동 3가지, 선물상자 찾기로 특별 장식 열기
5. 아바타 꾸미기, 몸짓, 말풍선, 사진 찍기, 저장
6. (선택) 아바타·트리·대표 장식을 생성 모델 파일로 바꾸기

## 운영자가 폰으로 확인해 줄 것 (자동 검사로는 알 수 없음)
1. 폰에서 방이 너무 작게 보이지 않는지. 세로 화면에서는 방 폭이 화면 폭에 맞춰져 위아래가 남는다. 2단계에서 두 손가락 확대를 넣을 예정
2. 눌러서 걷기의 반응과 걷는 빠르기(`avatar.js` 의 `SPEED`)
3. 아바타 생김새(머리 모양·얼굴 크기). `avatar.js` 한 파일만 고치면 된다

## 구조
- `app.js` 렌더러·조명·카메라·누르기·키보드, `room.js` 거실과 트리(트리 치수는 `TREE`), `avatar.js` 아바타와 걷는 몸짓
- `path.js` 바닥 격자(12×12, 한 칸 0.5)와 길찾기, `kit.js` 도형 도우미
- `vendor/` three.js(MIT). 주방과 같은 파일이지만 폴더끼리 기대지 않게 따로 둔다
- `tests/` 자동 검사. 실행법은 `tests/README.md`
