# 네 컷 사진관: 지금 상태와 다음 할 일

주소: https://the-anatomix.github.io/gift/fourcut/ (놀자방 홈의 ROOMS 에 한 줄 넣으면 열린다)

## 지금 되는 것
- 처음 화면에서 고르기: 혼자 찍기 / 둘이 찍기(링크로 초대) / 앨범 사진으로 만들기
- 혼자 찍기: 앞 카메라(거울 보기) → "찍기" 한 번에 네 컷 연속, 컷마다 3·2·1 카운트다운 + 번쩍 + 셔터 소리
  - 소리는 음원 파일 없이 `sfx.js` 가 직접 만든다. 위쪽 🔈 로 끔
- 컷 보기: 네 컷 가운데 한 컷만 다시 찍기, 처음부터 다시 찍기
- 꾸미기: 프레임 7종(크림 / 초코 / 딸기 체크 / 민트 / 까만 필름 / 크리스마스 / 새해), 한마디 16자, 날짜 넣기·빼기
  - 프레임은 그림 파일 없이 `strip.js` 의 `FRAMES` 에서 그린다. 새 프레임은 한 줄 추가
- 완성 띠: 1080 x 3240 (가로:세로 1:3 세로 네 컷). 컷은 960 x 720 으로 담는다
- 저장하기(JPEG 내려받기), 공유하기(파일 공유가 되는 브라우저는 공유 창, 안 되면 저장으로 대신하고 안내). 미리보기를 길게 눌러 저장할 수도 있다
- 카메라가 없거나, 권한을 거부했거나, 앱 안 브라우저일 때: 짧은 안내 + "앨범에서 고르기"(여러 장). 세로·가로 사진은 가운데를 잘라 맞춘다. 덜 고르면 빈 칸에 한 장씩 넣는다
- 둘이 찍기: 한 사람이 방을 만들고 링크(`#r=방`)를 보냄 → 친구가 열고 들어옴 → 한 컷이 반으로 나뉘어 왼쪽은 방 주인, 오른쪽은 손님
  - 주인이 찍기를 누르면 두 폰이 같이 카운트다운하고 같은 순간에 찍는다. 각자 반쪽(480 x 720 JPEG)을 상대에게 보내 두 쪽이 같은 띠를 갖는다
  - 프레임·한마디·날짜는 누가 바꿔도 상대 화면에 따라간다. 손님도 "다시 찍기"를 누를 수 있다(주인 쪽에서 같이 다시 찍음)
  - 연결 상태 표시(기다리는 중 / 연결됨 / 친구가 나감). 친구가 중간에 나가면 찍은 컷은 그대로 두고 남은 컷은 혼자 이어 찍는다
  - 세 번째 사람은 "이미 두 명" 안내를 받는다. 카메라가 없는 사람도 앨범 사진으로 자기 자리를 채워 참여할 수 있다
- 사진은 서버에 올라가지 않는다. 서로를 찾는 데만 PeerJS 공개 브로커를 쓴다(바닥글에 적어 둠)

## 운영자가 폰으로 확인해 줄 것 (자동 검사로는 알 수 없음)
1. 카메라 권한: 아이폰 Safari, 안드로이드 Chrome 에서 권한 창 → 허용 / 거부 각각. 거부했을 때 안내와 앨범 단추가 보이는지
2. 카카오톡·인스타그램 안 브라우저: 링크를 눌러 열었을 때 안내가 뜨는지, 카메라가 실제로 막히는지(되는 기기도 있다), 앨범 고르기는 되는지, 저장이 안 될 때 길게 눌러 저장이 되는지
3. 둘이 찍기: 폰 두 대(한 대 와이파이, 한 대 데이터)로 초대 → 연결까지 걸리는 시간, 카운트다운이 거의 같이 가는지, 네 컷 반쪽이 다 도착하는지. 자동 검사는 같은 브라우저 안 통신만 확인했고, PeerJS 공개 브로커를 거친 실제 연결은 클라우드에서 확인하지 못했다
4. 둘이 찍다가 한 사람이 다른 앱으로 20초 넘게 나갔다 오면 끊긴 것으로 본다(`duo.js` 의 `T.silent`). 너무 짧거나 길면 조정
5. 공유 창: 아이폰·안드로이드에서 "공유하기"가 사진 파일로 인스타 스토리·카카오톡에 넘어가는지. 스토리에 올렸을 때 1:3 띠의 크기가 괜찮은지
6. 세로로 든 폰에서 찍힌 컷의 구도(4:3 으로 가운데를 자름), 둘이 찍을 때 반쪽(2:3) 구도, 셔터 소리 크기

## 정해 줄 것
- 띠 비율: 지금은 사진관 띠와 같은 1:3. 스토리 화면(9:16)에 꽉 차는 판이 필요하면 `strip.js` 에 배치만 더하면 된다
- 띠 아래 작은 글자 "놀자방 · 네 컷 사진관"을 둘지, 계정 이름으로 바꿀지 (`strip.js` 의 `drawStrip`)
- 끊긴 뒤 다시 연결: 지금은 다시 잇지 않고 혼자 이어 찍는다. 새 링크로 다시 만나면 처음부터 찍는다

## 구조
- `index.html` 화면 네 개(처음 / 찍기 / 컷 보기 / 꾸미고 저장)와 모양
- `app.js` 화면 흐름·카메라·앨범·저장·공유, `strip.js` 프레임과 완성 띠 그리기, `sfx.js` 효과음
- `duo.js` 둘이 찍기(주고받는 것은 파일 맨 위 주석), `net.js` 연결(PeerJS / 검사용 BroadcastChannel)
- `vendor/` PeerJS(MIT). 다른 폴더의 파일은 불러 쓰지 않는다
- `tests/` 자동 검사. 실행법은 `tests/README.md`
