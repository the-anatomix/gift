# 새해 소원 쪽지: 지금 상태와 다음 할 일

주소: https://the-anatomix.github.io/gift/wish/ (놀자방 홈의 카드는 아직 "준비 중". `nolja/index.html` 의 ROOMS 에서 `open: true, href: '../wish/'` 로 바꾸면 열린다)

## 지금 되는 것
- 쓰기: 편지지 위에 바로 적는다. 받는 사람·보내는 사람(각 12자, 비워도 됨), 소원 1~5개(각 60자), 덧붙이는 말(120자). 글자 수는 `codec.js` 의 `LIM`
- 편지지 6가지(크림, 복주머니 빨강, 민트 모눈, 새벽 별밤, 한지, 분홍 줄무늬). 그림 파일 없이 `index.html` 의 `.pp0`~`.pp5` 색·무늬만으로 그린다
- 열리는 날: 기본은 다가오는 1월 1일 0시. 설날 / 100일 뒤 / 1년 뒤 / 직접 고르기(날짜와 시각). 모두 이 기기의 현지 시각
- 접기: 아래 칸 → 위 칸 순서로 접히고 띠지와 "복" 도장이 찍힌다. 종이 소리 두 번과 도장 소리(`sfx.js`, 음원 파일 없음). 위쪽 버튼으로 소리 끔
- 접으면 이 기기의 "내 소원함"(localStorage `nolja.wish.box.v1`)에 담기고, 주소가 쪽지 링크(`#w=…`)로 바뀐다
  - 나에게 보관: 링크 복사(메모나 나와의 채팅에 붙여 두는 용도)
  - 친구·연인에게 보내기: 공유 창 → 복사 → 직접 복사 순서(놀자방 홈과 같음)
- 그날 전: 접힌 쪽지와 남은 시간. D-48 처럼 보이다가 마지막 24시간은 시:분:초. 눌러도 펼쳐지지 않고 언제 열리는지 알려 준다. 잠긴 동안에는 소원 글자를 화면에 아예 넣지 않는다
- 그날부터: 쪽지가 빛나고, 누르면 펼쳐지며 색종이가 날린다. 1월 1일에 열리는 쪽지(또는 1월 1일에 펼친 쪽지)에는 해돋이 그림
- 받은 사람: 링크를 열면 받은 쪽지로 소원함에 담기고 "답장 쪽지 쓰기"가 나온다. 답장은 받는 사람·보내는 사람이 채워져 있고, 받은 쪽지와 같은 날 열리게 맞춰진다
- 펼친 뒤: 소원마다 "이뤘어요"를 눌러 표시. 쪽지 아래와 소원함 위쪽에 "이룬 소원 n / m"
- 읽을 수 없는 링크(잘림, 바뀜, 너무 김)는 "쪽지를 읽을 수 없어요" 화면. 저장소 값이 망가져 있어도 멀쩡한 쪽지만 골라 쓴다. 저장소를 못 쓰는 브라우저에서는 링크만으로 동작
- 움직임 줄이기(prefers-reduced-motion)를 켠 사람에게는 접는 움직임과 색종이를 뺀다

## 잠금에 대해 (솔직하게)
서버가 없어서 잠금은 이 화면 안에서만 지켜진다. 기기 시계를 앞으로 돌리거나 링크를 풀어 보면 그날 전에도 읽을 수 있다.
링크의 내용은 주소창을 흘끗 봐서는 읽히지 않게 가볍게 섞었을 뿐이고(XOR + base64url) 암호가 아니다. 화면 아래에도 그렇게 적어 두었다.
"안전하다", "비밀이 지켜진다" 같은 말은 소개 글에도 쓰지 않는 것이 좋다.
이름이나 연락처는 받지 않는다. 쪽지는 링크 안과 그 기기의 소원함에만 있다. 서버로 가는 것은 없다.

## 운영자가 폰으로 확인해 줄 것 (자동 검사로는 알 수 없음)
1. 키보드: 소원 칸·덧붙이는 말·보내는 사람 칸을 눌렀을 때 키보드에 가려지지 않는지(아이폰 사파리, 갤럭시 크롬·삼성 인터넷). 한글 조합 중 엔터를 눌렀을 때 글자가 깨지지 않는지
2. 직접 고르기의 날짜·시각 칸이 폰에서 잘 열리는지(아이폰은 휠, 안드로이드는 달력)
3. 접는 움직임과 소리: 무음 모드가 아닐 때 종이 소리·도장 소리가 들리는지, 접히는 속도가 답답하지 않은지(`app.js` 의 `foldAnim` 안 숫자)
4. 링크를 카카오톡·인스타 DM·문자로 보냈을 때 끝까지 붙는지(가장 긴 쪽지는 링크가 3천 자쯤 된다), 앱 안 브라우저에서 열리는지
5. 앱 안 브라우저에서 연 쪽지는 그 앱의 소원함에 담긴다. 사파리·크롬의 소원함과는 따로다. 헷갈리면 안내 문구가 필요한지
6. 실제로 그날을 넘겨 보기: 직접 고르기로 2~3분 뒤를 맞춰 접고, 화면을 켜 둔 채와 껐다 켠 뒤 모두 제때 빛나는지
7. 설날 날짜 표(`dates.js` 의 `SEOLLAL`, 2027~2034년)를 달력과 한 번 대조. 브라우저의 한국 음력 계산으로 맞춰 봤지만 천문연구원 발표와 직접 대조하지는 못했다

## 정해 줄 것
- 놀자방 홈 카드 문구. 예: "소원을 적어 접어 두면 정한 날에 열려요. 서로 주고받고, 이룬 소원도 표시해요."
- 글꼴: 바깥 글꼴을 쓰지 않아서 간판이 홈(Jua)보다 얇게 보인다. 홈과 똑같이 맞추려면 글꼴 파일을 저장소에 넣어야 한다
- 받은 쪽지를 묻지 않고 소원함에 담는 것(지금 방식)이 좋은지, "담아 둘까요?"를 물을지
- 미리보기 그림(og:image)은 아직 없다

## 다음에 하면 좋은 것 (순서 제안)
1. 폰 확인에서 나온 조작감 수정
2. 쓰던 글 임시 저장(지금은 접기 전에 새로 고치면 사라진다)
3. 둘이 같은 날 같이 펼치기: 서로의 쪽지가 둘 다 소원함에 있으면 나란히 보여 주기
4. 연말 돌아보기: 12월에 "올해 이룬 소원" 카드 한 장(사진으로 저장)
5. 설날 판: 설날에 열리는 쪽지에는 해돋이 대신 복주머니 그림

## 구조
- `index.html` 화면과 모양(편지지 무늬, 접는 쪽지, 해돋이 모두 CSS/SVG)
- `app.js` 화면 흐름: 쓰기 · 접기 · 쪽지 보기(남은 시간, 펼치기, 이뤘어요) · 보내기 · 답장 · 소원함 · 색종이
- `dates.js` 열리는 날 계산(새해 첫날, 설날 표, 100일 뒤, 1년 뒤, 남은 시간, 잠김/열림). 화면을 건드리지 않는 작은 함수들
- `codec.js` 쪽지 ↔ 링크. `#w=` 뒤는 [판 번호 1][씨앗][섞은 JSON + 합계 2바이트] 를 base64url 로 적은 것. 글자 수 다듬기(`tidy`)도 여기
- `store.js` 내 소원함(localStorage), `sfx.js` 소리
- `tests/` 자동 검사. 실행법은 `tests/README.md`
