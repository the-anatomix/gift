# 새해 소원 쪽지 자동 검사

화면 없는 브라우저(Playwright Chromium)로 폰 크기 화면을 띄워 쪽지를 쓰고, 접고, 시계를 돌려 펼쳐 봅니다.

## 준비

```bash
cd wish/tests
npm install            # playwright 를 받습니다 (이미 깔려 있으면 건너뜁니다)
npx playwright install chromium
```

## 실행

```bash
node dates.test.js    # 열리는 날 계산: 새해 첫날 · 설날 표 · 100일 뒤 · 1년 뒤 · 남은 시간 · 해가 바뀌는 밤의 화면
node link.test.js     # 쪽지 링크(#w=…): 한글 · 이모지 · 글자 수 끝까지 · 바뀌거나 잘린 링크 · 망가진 저장소
node flow.test.js     # 쓰기 → 접기 → 소원함 → 남은 시간 → 정각에 열림 → 펼치기 → 이뤘어요 → 답장 · 화면 폭 360~430px
npm test              # 셋 다
```

결과는 줄마다 `통과` / `실패` 로 나오고, 화면 사진은 `out/` 에 남습니다(커밋하지 않음).
`lib.js` 는 세 검사가 같이 쓰는 작은 정적 서버와 브라우저 준비입니다.

## 시계

검사는 `page.clock` 으로 브라우저의 시계를 정해 두고 움직입니다(시간대는 Asia/Seoul).
앱은 `Date.now()` 만 보기 때문에 실제로 기다리지 않고 12월 31일 23:59:59 → 1월 1일 0:00:00 을 확인합니다.

## 이 검사로 알 수 없는 것

실제 폰의 키보드가 올라올 때의 화면(검사는 화면 높이를 줄여 흉내만 냅니다), 소리가 실제로 들리는지,
카카오톡·인스타그램 안 브라우저에서 링크가 잘리지 않는지, 공유 창(navigator.share)의 실제 모습은
사람이 기기로 직접 확인해야 합니다.
