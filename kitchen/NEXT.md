주소: https://the-anatomix.github.io/gift/kitchen/

## 지금 되는 것
- 처음 화면에서 고르기: 혼자 굽기 / 둘이 같이 굽기(한 과자를 함께) / 둘이 서로 선물(각자 구워 주고받기)
- 자리 7곳: 반죽 → 자르기 → 굽기 → 초콜릿 → 토핑(글자 새기기 6자와 글자색) → 포장(상자 4종)
- 탭에 ☆(완성) ★(완벽) 표시, 전체 화면에 "다음 차례" 안내
- 과자 등급 세 단계(네 자리를 다 해야 붙음): 수제(★ 0~1) / 고급 수제(★ 2~3) / 최고급 수제(★ 넷). 이름은 `stations/pack.js` 의 `TITLES`
- 자리마다 화면 가운데에 PERFECT! / GOOD 판정 표시
  - ★ 기준: 반죽은 손을 떼지 않고 한 번에, 자르기는 눈금에 맞춰 곧게 다섯 번, 굽기는 가운데 선에서 0.07초 안쪽, 초콜릿은 과자의 금에 맞춰 한 번에
  - 기준 값: `stations/cut.js` 의 `TOL`·`STRAIGHT`, `stations/oven.js` 의 `BEST_TOL`, `app.js` 의 `DIP.tol`
- 포장 완료 → 반죽이(마스코트)가 뛰며 좋아함 → 편지 쓰기 → 선물 링크(`#g=…`) 또는 연결된 상대에게 바로 선물
- 받는 사람: 주방 없이 선물만 보임 → 화면을 밀면 시점이 돌아감 → 열어 보기 → 과자가 상자 밖으로 나와 크게 보임 → 봉투를 누르면 편지가 나오고(오르골 배경음악, 끄기 버튼) 다시 누르면 들어감. 편지는 아래, 과자는 위라 서로 가리지 않음
- 효과음(`sfx.js`): 반죽·자르기·오븐·초콜릿·토핑·포장 (PERFECT/GOOD 판정에는 소리 없음). 음원 파일 없이 직접 만들어 내는 소리. 위쪽 🔈 버튼으로 효과음과 편지 음악을 함께 끔
- 배경음악은 음원 파일 없이 `bgm.js` 가 직접 연주(직접 지은 곡). 음을 바꾸려면 `BARS`·`TUNE`
- 자랑 카드(받는 사람): 선물 상자·꺼낸 과자·편지·만든 과정 결과가 담긴 사진 한 장. 내 사진은 폴라로이드로 붙일 수 있음
- 자랑 카드(만든 사람): 포장 뒤 "만든 과정 자랑 카드". 자리마다 저절로 찍힌 과정 사진 네 장과 PERFECT/GOOD, 등급, 완성된 과자
- 편지: 첫 줄·끝 줄을 자유롭게 쓰고, 보내기 전에 편지지 미리보기 가능
- 선물 링크는 두 가지 중 보내는 사람이 고름: 기본 링크(내용이 링크 안에만) / 짧은 링크(외부 단축 서비스 is.gd 에 내용이 저장됨). 실제 is.gd 동작은 클라우드에서 확인하지 못했으니 폰으로 확인 필요
- 끊기면 혼자 이어 굽기, 다시 연결, 이어 굽기 링크(`#s=…`)
- 앱 안 브라우저 안내, WebGL 없으면 2D 판 안내, 저사양 단계, 계절 판 설정(theme.js)
- 크리스마스 판(`theme.js` 의 `xmas`): 12월 1일~25일(기기의 현지 날짜)에는 저절로 열린다. 위 막대에 "🎄 크리스마스 판" 이름표
  - 주방: 초록·빨강·금빛 색, 바닥의 작은 트리와 선물, 벽의 리스, 꼬마전구 줄, 눈 내리는 창(밤하늘·달·쌓인 눈). 눈과 전구는 주방이 쉬는 동안에도 1초에 열 번쯤만 그리고(저사양 단계에서는 네 번쯤) 그림자는 다시 만들지 않는다. "움직임 줄이기" 설정이면 멈춰 있다
  - 고를 수 있는 것: 포장 상자(크림·빨강·초록·금빛), 글자색(초록·금빛), 스프링클 색(빨강·초록·금빛·흰색). 가짓수는 기본 판과 같다
  - 받는 화면: "크리스마스 선물이 도착했어요", 받침 위 작은 트리와 선물, 내리는 눈, 눈꽃 편지 장식. 자랑 카드도 초록빛 바탕에 눈송이, 아래에 "크리스마스 판"
  - 음악과 효과음은 기본 판과 같다(캐럴은 넣지 않았다)

## 계절 판은 이렇게 정해진다
1. 주소의 `?theme=xmas` / `?theme=base` 가 가장 먼저다(모르는 이름은 무시)
2. 선물 링크(`#g=…`)는 만든 사람의 판으로 열린다. 계절 판에서 만든 선물만 링크 안에 `t`(판 이름)가 하나 더 담긴다. 기본 판 링크는 예전과 한 글자도 다르지 않고, `t` 가 없는 예전 링크는 12월에 열어도 기본 판으로 열린다
3. 둘 다 없으면 날짜(`theme.js` 의 `seasonOf`)
- 초대·이어 굽기 링크(`#r=` `#x=` `#s=`)는 날짜로 계절 판이 정해졌을 때 `?theme=xmas` 를 붙여 보낸다(자정·시차가 달라도 둘이 같은 판)
- "나도 만들기"를 누르면 선물 링크가 떨어지므로 그날 날짜의 판으로 주방이 열린다

## 새 계절 판을 더하려면 (`theme.js` 만 고치면 된다)
1. `THEMES` 에 항목 추가: `id`, `name`, `colors`(기본 색에 덮어쓸 것만), `ui`(CSS 변수: `--bg` `--choc` `--accent`, 배경 `--bg1~3`, 받는 화면 배경 `--rv1~3`), `props(k)`(소품. 움직이면 `tick(지금 시각)` 함수를 돌려준다)
2. 원하면: `tag`(위 막대 이름표), `boxes`·`textColors`·`sprinkle`(가짓수는 기본 판과 같게: 링크에는 번호만 담긴다), `stage(k, 받침)`(받는 화면 소품), `hello`·`orn`·`sparks`·`snow`(받는 화면), `card`(자랑 카드 색)
3. `seasonOf` 에 날짜 한 줄. 소품 묶음의 이름은 `season`, 소품마다 `name` 을 주면 `__kitchen.season()` 으로 검사할 수 있다
4. `tests/theme.test.js` 에 그 판의 날짜·소품 검사를 더한다

## 운영자가 폰으로 확인해 줄 것 (자동 검사로는 알 수 없음)
1. 각 자리의 터치감: 반죽이 3~5초에 끝나는지(`stations/dough.js` 의 `7 * Math.max(320, i.w)`), 자르기 긋기, 굽기 게이지 속도(`stations/oven.js` 의 `BAKE_MS`)
2. 둘이 서로 선물: 폰 두 대(한 대 와이파이, 한 대 데이터)로 초대 → 각자 포장 → "상대에게 바로 선물하기" → 상대 폰에 "선물이 도착했어요"
3. 선물 링크를 카카오톡·인스타 DM 으로 보냈을 때 열리는지, 앱 안 브라우저 안내가 뜨는지
4. 편지 칸에서 폰 키보드가 올라왔을 때 입력칸이 가려지지 않는지
5. 한글 글자 새기기의 굵기와 크기(폰 글꼴 기준)
