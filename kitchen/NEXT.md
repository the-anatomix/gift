# 미니 주방: 지금 상태와 다음 할 일

주소: https://the-anatomix.github.io/gift/kitchen/

## 지금 되는 것
- 처음 화면에서 고르기: 혼자 굽기 / 둘이 같이 굽기(한 과자를 함께) / 둘이 서로 선물(각자 구워 주고받기)
- 자리 7곳: 반죽 → 자르기 → 굽기 → 초콜릿 → 토핑(글자 새기기 6자와 글자색) → 포장(상자 4종)
- 탭에 ☆(완성) ★(완벽) 표시, 전체 화면에 "다음 차례" 안내
- 과자 등급 세 단계(네 자리를 다 해야 붙음): 수제(★ 0~1) / 고급 수제(★ 2~3) / 최고급 수제(★ 넷). 이름은 `stations/pack.js` 의 `TITLES`
- 자리마다 화면 가운데에 PERFECT! / GOOD 판정 표시
  - ★ 기준: 반죽은 손을 떼지 않고 한 번에, 자르기는 눈금에 맞춰 곧게 다섯 번, 굽기는 가운데 선에서 0.07초 안쪽, 초콜릿은 과자의 금에 맞춰 한 번에
  - 기준 값: `stations/cut.js` 의 `TOL`·`STRAIGHT`, `stations/oven.js` 의 `BEST_TOL`, `app.js` 의 `DIP.tol`
- 포장 완료 → 반죽이(마스코트)가 뛰며 좋아함 → 편지 쓰기 → 선물 링크(`#g=…`) 또는 연결된 상대에게 바로 선물
- 받는 사람: 주방 없이 선물만 보임 → 화면을 밀면 시점이 돌아감 → 열어 보기 → 과자가 상자 밖으로 나와 크게 보임 → 봉투를 누르면 편지가 나오고(오르골 배경음악, 끄기 버튼) 다시 누르면 들어감. 편지는 아래, 과자는 위라 서로 가리지 않음
- 효과음(`sfx.js`): 반죽·자르기·오븐·초콜릿·토핑·판정·포장. 음원 파일 없이 직접 만들어 내는 소리. 위쪽 🔈 버튼으로 효과음과 편지 음악을 함께 끔
- 배경음악은 음원 파일 없이 `bgm.js` 가 직접 연주(직접 지은 곡). 음을 바꾸려면 `BARS`·`TUNE`
- 자랑 카드(받는 사람): 선물 상자·꺼낸 과자·편지·만든 과정 결과가 담긴 사진 한 장. 내 사진은 폴라로이드로 붙일 수 있음
- 자랑 카드(만든 사람): 포장 뒤 "만든 과정 자랑 카드". 자리마다 저절로 찍힌 과정 사진 네 장과 PERFECT/GOOD, 등급, 완성된 과자
- 편지: 첫 줄·끝 줄을 자유롭게 쓰고, 보내기 전에 편지지 미리보기 가능
- 끊기면 혼자 이어 굽기, 다시 연결, 이어 굽기 링크(`#s=…`)
- 앱 안 브라우저 안내, WebGL 없으면 2D 판 안내, 저사양 단계, 계절 판 설정(theme.js)

## 운영자가 폰으로 확인해 줄 것 (자동 검사로는 알 수 없음)
1. 각 자리의 터치감: 반죽이 3~5초에 끝나는지(`stations/dough.js` 의 `7 * Math.max(320, i.w)`), 자르기 긋기, 굽기 게이지 속도(`stations/oven.js` 의 `BAKE_MS`)
2. 둘이 서로 선물: 폰 두 대(한 대 와이파이, 한 대 데이터)로 초대 → 각자 포장 → "상대에게 바로 선물하기" → 상대 폰에 "선물이 도착했어요"
3. 선물 링크를 카카오톡·인스타 DM 으로 보냈을 때 열리는지, 앱 안 브라우저 안내가 뜨는지
4. 편지 칸에서 폰 키보드가 올라왔을 때 입력칸이 가려지지 않는지
5. 한글 글자 새기기의 굵기와 크기(폰 글꼴 기준)

## 정해 줄 것
- 마스코트: 사람 캐릭터를 넣지 않는다는 조건에 맞춰 반죽 덩어리 모양(반죽이)으로 만들었다. 다른 모습을 원하면 `stations/pack.js` 의 "반죽이" 부분만 바꾸면 된다.
- 계정 이름: `theme.js` 의 `SITE.account` 에 넣으면 위 막대에 표기된다.
- 루트 2D 판과의 관계: 지금은 서로 링크만 한다(주방 → "2D 판"). 주방을 기본으로 바꿀지.
